# 🏝️ Island Game

Island Game is a browser-based mini-game collection featuring arcade challenges, puzzles, and casual games. Players can earn coins, gain experience points (XP), level up, unlock achievements, and save their progress.

## ✨ Features

- 🎮 12 playable mini-games
- 🪙 Coins and rewards system
- ⭐ XP and player levels
- 🏆 Achievements
- ❤️ Favorite games
- 🔍 Game search and category filters
- 📊 High scores and progress tracking
- 💾 Export and import saved progress
- 📱 Responsive design for mobile and desktop
- ⛶ Fullscreen support

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern web browser.
4. Choose a game and start playing!

No installation or external libraries are required for the basic version.

## 💾 Save Data

Island Game uses browser Local Storage to save player progress, including coins, XP, levels, favorites, achievements, and high scores.

Use the **Export Backup** option to download your progress as a JSON file. Use **Import Backup** to restore a previously exported backup.

**Note:** Saved data is stored in the browser on the current device. Clearing browser data may remove your progress, so export a backup regularly.

## 📱 Mobile Support

The interface is designed to adapt to mobile phones, tablets, and desktop screens. Some games support touch controls, while others may be easier to play with a keyboard.

## 🔒 Privacy

The game does not require an account or server for its basic features. Progress is stored locally in the browser.
